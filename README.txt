  # 🗺️ Tarih Atlası

  BTE302 dersi kapsamında geliştirilen, Orta Çağ tarihini interaktif harita
  üzerinden öğreten browser tabanlı bir oyunlaştırma projesidir.

  ## 🎮 Özellikler

  - İpek Yolu güzergahı üzerinde 6 şehri gezen interaktif harita
  - Öğrenci / Öğretmen giriş sistemi
  - 9 tarih konusu: Bizans, İslam, Türk Devletleri, Selçuklu, Haçlı Seferleri,
    Moğollar, İpek Yolu, Feodal Avrupa, Osmanlı
  - Her bölüm için quiz ve XP sistemi
  - Akçe tabanlı karakter mağazası
  - Sınıf liderboard ve ödev (ferman) sistemi

  ## 🚀 Nasıl Çalıştırılır?

  1. Repoyu indir veya klonla
  2. `tarih-atlasi-yeni.html` dosyasını tarayıcıda aç
  3. `ipekyolu/` klasörü HTML ile aynı dizinde olmalı

  > İnternet bağlantısı olmadan da çalışır; yalnızca Google Fonts yüklenemez.

  ## 🛠️ Kullanılan Teknolojiler

  - HTML5 / CSS3 / Vanilla JavaScript
  - SVG tabanlı interaktif harita
  - Google Fonts (Cinzel, Crimson Text)
